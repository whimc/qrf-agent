Read a text description of the relationships
  • Shared activity data: Science Tools writes measurements, Observations writes student observations, and Position Tracker writes movement samples and region events. Student Feedback reads activity and writes progress scores.
  • qrf-agent: optionally reads learner context from compatible MySQL tables and writes agent, dialogue and chat research records. Its learner-context movement input uses position samples, not the separate region-event table.
  • Runtime capabilities: Citizens supplies NPCs and traits; Journey supplies destinations and accepts navigation commands; WorldGuard supplies regions and points of interest; CoreProtect supplies building history; ProtocolLib supports sign input.
  • Supporting plugins: Observations requires DecentHolograms and ProtocolLib. WorldGuard also supports region-aware science tools and optional Position Tracker region tracking.
  • Content and services: reference files supply bounded text excerpts. A configured hosted or local language model can receive prompts and selected context and return replies. A separate local PMML dialogue path also exists. Habitat Assesser receives assessment events and bridges an external Socket.IO service.
  • Dependencies needing verification: HolographicDisplays is declared in qrf-agent, but direct API calls were not identified. The inspected SpeechReceiver hookup and old science-tool event listener are commented out.

Implemented paths may require optional configuration and compatible database access. This map describes the inspected source, not a verified live server deployment.
